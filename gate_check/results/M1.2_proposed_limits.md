# M1.2 — proposed plausibility limits, for confirmation before M4

Derived from the **conceptual model in the configs** — each unit's stated
porosity, clay fraction and pore-water conductivity — and from generic
hydrogeophysical ranges for those lithology classes. **No truth output was used
to set any limit.** The truth means are then checked against the proposal and
reported, not fitted to.

Configs: `synthetics/config/paper_3P.toml` (sha256 `18bd80b0b237a2f6`) and
`synthetics/config/confined_aquifer.toml` (sha256 `efa2744e3e101a16`).

## Lithology classes, assigned from the config's clay fraction

**Not from the unit name.** 2P's first unit is called "Shepparton Fm,
unsaturated" but the config gives it clay = 0.40, so it is a clayey cover, not a
clean one. Classifying it by its name would put it in the clean-cover class and
its true mean would fall outside by a factor of seven. The stated clay fraction
is the conceptual model; the name is a label.

| class | config signature | proposed sigma range (S/m) |
|---|---|---|
| 1. cover, clean sand, unsaturated | clay <= 0.10, above the water table | 0.0005 – 0.05 |
| 2. cover, clayey, unsaturated | clay > 0.35, above the water table | 0.02 – 1.0 |
| 3. clay cap or aquitard | clay > 0.35, saturated | 0.05 – 3.0 |
| 4. aquifer sand | clay <= 0.10, saturated | 0.002 – 0.3 |
| 5. silty sand or weathered rock | 0.10 < clay <= 0.35 | 0.01 – 1.0 |
| 6. fresh crystalline basement | clay <= 0.05 and phi <= 0.05 | 0.0002 – 0.05 |

## Boundary buffer

**Proposed: 3 m either side of each stated boundary**, within which only the
global bounds apply. The justification is in the configs themselves:
`[variability].transition_min = 3.0` and `transition_max = 6.0`, so the truth's
own unit contacts are gradational over 3–6 m. A buffer narrower than the
conceptual model's own transition width would impose a limit where the
conceptual model does not claim a single lithology.

## SNMR physical floor inside the window

    sigma_floor = sigma_w(freshest plausible) * theta_low ^ m_max

with `theta_low` the lowest p05 of window water content across the ensembles and
`m_max` the prior's upper exponent. Proposed freshest plausible water:
**50 mg/L**, i.e. sigma_w = 50/6400 = 0.0078 S/m — rainwater-fresh, so a genuine
floor rather than an assumption about this aquifer.

On 3P: theta_low = 0.265, m_max = 1.9, so

    sigma_floor = 0.0078 * 0.265^1.9 = 0.000626 S/m

against a true window mean of 0.02689 S/m. A weak floor in absolute terms, but
**six times the global floor of 1e-4**, which is what matters: at the top of the
data-only band five or six window cells sit pinned at 1e-4, and this floor would
lift them.

## Expected effect, stated in advance

From `whole_profile_3P.md`, the models at the top of the data-only band reach it
by driving the cover to the global floor (all five cells pinned at 1e-4, 91x
below truth) and the basement to 28.6 S against a true 0.87 S. The proposed
limits bite on exactly those two:

- cover class 1 floor **0.0005** against the global 1e-4 — five times higher;
- basement class 6 ceiling **0.05 S/m**, which caps the 88–200 m interval at
  about 5.6 S against the 28.6 S the data-only model used.

So the with-limits band should be **materially narrower at the top**, which is
the point. I am recording that expectation now so the result is a test of it
rather than a description after the fact.

Nothing here is applied until confirmed.
